# Tender

This repository contains the Tender frontend and backend applications.

## Projects

- `frontend/` — Next.js frontend
- `mak-new-tender/` — Django backend

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd mak-new-tender
python -m pip install -r requirements.txt
python manage.py runserver
```

Environment variables and service credentials must be configured locally and must not be committed.
